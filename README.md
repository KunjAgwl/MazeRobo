Left First (L)
Action: Look to your left relative to current facing direction

Condition: If the left path is clear → turn left and move forward

Record: Mark this move as L

Purpose: Ensures you always explore leftward paths first

2. ⬆️ Try Straight Second (S)
Action: If left is blocked, check straight ahead

Condition: If the forward path is clear → move straight

Record: Mark this move as S

Purpose: Maintains current trajectory when possible

3. ➡️ Try Right Third (R)
Action: If both left and straight are blocked, check right

Condition: If the right path is clear → turn right and move forward

Record: Mark this move as R

Purpose: Explores remaining options before giving up

4. 🔙 Turn Back Last Resort (B)
Action: If left, straight, and right are all blocked (dead end)

Condition: Turn 180 degrees and move backward

Record: Mark this move as B

Purpose: Escapes dead ends and continues exploration
